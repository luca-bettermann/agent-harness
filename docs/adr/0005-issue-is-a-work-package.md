# An issue is a planning unit; a session is a day's bundle

Every agent session pays a fixed cost (orientation of 100–300k tokens, a worktree, a CI round, a review), and narrow sessions in the same area conflict on one branch. Every issue costs the operator attention on the board. So an issue exists only for work that needs planning or its own proof; smaller items are checklist lines on an issue. A session takes a bundle of about one day from one project and area; a larger project runs as several sessions. The installation's tracker mapping holds the rule.
