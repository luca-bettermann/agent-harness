# Knowledge

- `SCHEMA.md`: the rules every knowledge module imports.
- `module/`: the skeleton for a new module. Copy it once, and the install replaces `<agent-harness>` with the harness path. The rules then arrive through the import. A shared wiki whose readers lack agent-harness vendors a copy of `SCHEMA.md` instead, updated deliberately.
- `drafts/`: writing skills not yet mature enough to load (Academic Writing, Literature Review, Visual Identity).
