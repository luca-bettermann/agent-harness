Follow [`to-tickets`](../upstream/skills/engineering/to-tickets/SKILL.md) exactly, with these changes. Where other skills say `to-tickets` or "ticket", they mean this skill and a Linear issue.

- **Target:** the issues belong to the Linear project the work is part of; they are not sub-issues of the project description.
- **Single item:** a single thing to track becomes one issue. Skip the slicing, still quiz the user on the title and acceptance criteria.
